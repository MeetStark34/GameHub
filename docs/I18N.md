# Languages (i18n)

Supported: **EN** (default), **FR**, **HI**, **RU**.

| File | Purpose |
|---|---|
| `src/i18n/config.ts` | Language list, default, cookie name, Accept-Language fallback |
| `src/i18n/messages/en.ts` | English source of truth (every key) |
| `src/i18n/messages/{fr,hi,ru}.ts` | Translations (typed; anything missing falls back to English) |
| `src/i18n/messages/index.ts` | Dictionary registry |
| `src/i18n/translate.ts` | `createTranslator`: `t`, `list`, `msg`, `num`, `{param}` and `@key` params |
| `src/i18n/server.ts` | `getLocale()` / `getTranslator()` for server components and routes |
| `src/i18n/client.tsx` | `I18nProvider`, `useI18n()`, `setLocale()` |

**Locale resolution**: `gh-lang` cookie (explicit choice) > account
preference (`preferences.language`) > browser `Accept-Language` (first visit
only) > English.

**Switching**: header language menu or Settings → Language. This sets the
cookie, saves to the account when signed in, and re-renders server
components.

**Server text** (engine feedback, API errors, notifications) is sent as a
`Msg` (`{ key, params }`); the browser renders it in the player's language.
API errors include English `error` text plus a `code` key. Stored
notifications keep their keys in `data.i18n`, so they render in whatever
language the player uses later.

**Not translated, by design**: game names, rank names, the GameHub brand,
and the puzzle content of the English word games (Werd words, Crossclimb
words and clues, Pinpoint clues and categories, which players type in
English). The admin/developer dashboard is English-only.

**Adding a language**: add it to `LOCALES` in `config.ts`, create
`messages/<code>.ts` typed as `Translation`, and register it in
`messages/index.ts`. `src/i18n/i18n.test.ts` then fails until every key is
translated with matching `{placeholders}`.

**Tests**: key completeness, placeholder parity, achievement coverage, a
mostly-not-English heuristic, source-referenced keys exist, fallback and
interpolation (unit). E2E (`tests/e2e/language.spec.ts`): switching,
persistence across reloads, translated server game messages, and the
browser-language fallback losing to an explicit choice.
